# Cris Lopes Art

Portfólio profissional da **Cris Lopes Art**, desenvolvido para apresentar meus serviços, projetos e soluções digitais.

🌐 Site: https://www.crislopesart.com.br

## Sobre o projeto

O site Cris Lopes Art foi desenvolvido como meu portfólio profissional, reunindo serviços de Web Design, Desenvolvimento Front-end, Lojas Virtuais e soluções digitais.

O projeto apresenta meus trabalhos, formas de contato e páginas específicas para produtos e serviços.

## Principais recursos

- Portfólio de projetos
- Apresentação de serviços
- Página de etiquetas escolares
- Página de links
- Navegação responsiva
- Integração com WhatsApp
- SEO básico com sitemap e robots.txt
- Domínio personalizado
- Publicação pelo GitHub Pages

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Pages

## Estrutura do projeto

- `assets/` — imagens e recursos visuais
- `etiquetas-escolares/` — página do produto Etiquetas Escolares
- `links/` — página de links da Cris Lopes Art
- `index.html` — página principal
- `style.css` — estilos do site
- `script.js` — interações e funcionalidades
- `CNAME` — configuração do domínio personalizado
- `robots.txt` — configuração para mecanismos de busca
- `sitemap.xml` — mapa do site
